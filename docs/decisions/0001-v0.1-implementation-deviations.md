# Decision: Track incomplete release gates explicitly

- Date: 2026-07-22
- Status: accepted
- Project: herdr-logbook

## Context

The implementation brief requires real-host verification on Linux, Intel macOS, Windows, WSL, PowerShell 5.1/7, Bash, and Zsh before calling v0.1.0 complete. This workspace can directly verify only macOS Apple Silicon and cross-compilation. It also requests a Bubble Tea decision form; the current title-less CLI uses a line prompt while the Hub uses its existing modal.

## Decision

Keep the manifest version pre-stable, state the unverified rows in documentation, and avoid claiming v0.1.0 completion. Treat the line prompt as a temporary narrow implementation; `decision --title` and Hub `d` provide the complete safe creation path.

## Consequences

Release automation and installers exist but a public stable release remains blocked on the manual matrix, installer fresh-profile tests, screenshots, and a native PowerShell syntax run.

## Follow-up

Run the documented matrix on real hosts and replace the CLI line prompt with the same Bubble Tea title form if direct CLI usage shows the need.
